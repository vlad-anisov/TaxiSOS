# Как использовать "Избранное" для отправки видео самому себе

## Описание

В приложении SOSTaxi теперь есть возможность отправлять видеосегменты самому себе через специальный контакт **"⭐ Избранное"**.

Это удобно для:
- 📱 Личного хранения важных видеозаписей
- ☁️ Автоматического резервного копирования в облако Telegram
- 🔄 Доступа к видео с любого устройства
- 🔒 Конфиденциального сохранения без отправки другим людям

## Как настроить

### Шаг 1: Откройте настройки приложения

1. Запустите приложение SOSTaxi
2. Нажмите кнопку **"Настройки"** (⚙️)

### Шаг 2: Войдите в Telegram

Если вы еще не авторизованы:

1. Нажмите **"Войти в Telegram"**
2. Введите свой номер телефона
3. Введите код подтверждения из SMS
4. Если включена двухфакторная аутентификация - введите пароль

### Шаг 3: Выберите "Избранное"

1. После успешной авторизации нажмите **"Выбрать контакты"**
2. В самом начале списка вы увидите **"⭐ Избранное"**
3. Поставьте галочку напротив **"⭐ Избранное"**
4. При желании выберите и другие контакты для отправки
5. Нажмите **"Сохранить"**

### Шаг 4: Готово!

Теперь при записи видео все сегменты будут автоматически отправляться:
- В ваш чат **"Избранное"** (если выбрано)
- Другим выбранным контактам (если есть)

## Как это работает

### Запись и отправка видео

1. **Нажмите кнопку "START"** (или Bluetooth-кнопку)
   - Начнется запись видео

2. **Видео автоматически разбивается на сегменты**
   - По умолчанию каждый сегмент длится 60 секунд
   - Длительность можно изменить в настройках (от 10 до 300 секунд)

3. **Каждый сегмент автоматически отправляется**
   - В ваше "Избранное" в Telegram
   - Другим выбранным контактам

4. **Нажмите кнопку "STOP"** когда закончите запись

### Где найти отправленные видео

В приложении **Telegram**:

1. Откройте Telegram на любом устройстве
2. Найдите чат **"Избранное"** (Saved Messages)
   - На iOS: в списке чатов вверху
   - На Android: в списке чатов вверху
   - На Desktop: в левой панели чатов
3. Там будут все ваши видеосегменты

## Преимущества использования "Избранного"

### ✅ Автоматическое облачное хранение
- Все видео автоматически загружаются в облако Telegram
- Не занимают место на телефоне
- Не теряются при смене устройства

### ✅ Доступ с любого устройства
- Просматривайте видео на телефоне, планшете или компьютере
- Все синхронизируется автоматически

### ✅ Конфиденциальность
- Видео остаются только у вас
- Никто другой не имеет к ним доступа
- Можно выборочно пересылать нужные видео

### ✅ Удобная организация
- Все видео в одном месте
- Можно добавлять комментарии
- Можно пересылать в другие чаты
- Можно скачивать на устройство

## Комбинированное использование

Вы можете одновременно отправлять видео:

- ✅ **Себе** ("Избранное") - для личного хранения
- ✅ **Близким** (родственники, друзья) - для мониторинга
- ✅ **В группу** - для командной работы

Просто выберите несколько контактов при настройке!

## Проверка настроек

Чтобы убедиться, что "Избранное" выбрано:

1. Откройте **Настройки** приложения
2. Посмотрите на список выбранных контактов
3. Там должно быть **"⭐ Избранное"**
4. При необходимости нажмите **"Выбрать контакты"** для изменения

## Устранение проблем

### "Избранное" не появляется в списке контактов

**Решение:**
1. Убедитесь, что вы авторизованы в Telegram
2. Перезапустите приложение
3. Попробуйте выйти и снова войти в Telegram

### Видео не отправляются

**Решение:**
1. Проверьте подключение к интернету
2. Убедитесь, что "Избранное" выбрано в настройках
3. Проверьте разрешения приложения (камера, хранилище)
4. Посмотрите логи в Android Studio для деталей

### Видео не появляются в Telegram

**Решение:**
1. Откройте Telegram и обновите список чатов
2. Убедитесь, что используете ту же учетную запись
3. Проверьте папку "Избранное" (Saved Messages)

## Дополнительная информация

### Размер видео

- Telegram поддерживает видео до **2 ГБ**
- Рекомендуемая длительность сегмента: **60-120 секунд**
- Видео сжимаются автоматически для быстрой отправки

### Хранение видео

- Telegram хранит все файлы **неограниченное время**
- Можно хранить **неограниченное количество** файлов
- Видео доступны **даже после переустановки** приложения

### Безопасность

- Все видео передаются через **зашифрованное соединение**
- Доступ к "Избранному" есть только у вас
- Telegram не сканирует содержимое личных чатов

## Часто задаваемые вопросы

**Q: Можно ли отправлять только в "Избранное", без других контактов?**
A: Да! Просто выберите только "Избранное" в списке контактов.

**Q: Будут ли видео удалены, если я переустановлю приложение?**
A: Нет, видео останутся в Telegram. Вам нужно будет только заново войти в аккаунт.

**Q: Сколько места занимают видео на телефоне?**
A: После отправки видео можно удалить с телефона - они будут храниться в облаке Telegram.

**Q: Можно ли скачать все видео из "Избранного" на компьютер?**
A: Да, используйте Telegram Desktop и скачивайте нужные видео.

**Q: Есть ли ограничение на количество видео?**
A: Нет, в "Избранном" можно хранить неограниченное количество видео.
