# Bluetooth Button Integration - README

## Описание функционала

В приложение добавлен функционал работы с внешней Bluetooth-кнопкой. Теперь вы можете управлять запуском и остановкой записи/трансляции прямо с Bluetooth-кнопки, не открывая приложение.

## Возможности

✅ **Удобное управление**: Нажмите кнопку для запуска, нажмите снова для остановки  
✅ **Настраиваемое действие**: Выбирайте, что запускать - прямую трансляцию или видеосегменты  
✅ **Работает в фоне**: Приложение не обязательно должно быть открыто  
✅ **Совместимость**: Работает с большинством Bluetooth-кнопок (отправляющих медиа-события)  
✅ **Мультиязычность**: Поддержка русского, английского и польского языков  

## Как использовать

### 1. Подключите Bluetooth-кнопку к телефону

1. Включите Bluetooth на вашем телефоне
2. Переведите Bluetooth-кнопку в режим сопряжения
3. В настройках Bluetooth телефона найдите и подключите вашу кнопку

### 2. Настройте функционал в приложении

1. Откройте приложение SOSTaxi
2. Нажмите кнопку **"Настройки"**
3. Прокрутите вниз до раздела **"Настройки Bluetooth-кнопки"**
4. Включите **"Включить обработку Bluetooth-кнопки"**
5. Выберите действие при нажатии:
   - **Видео сегменты** - запись и отправка видео сегментами
   - **Видео трансляция** - прямая RTMP-трансляция
6. Нажмите **"Готово"**

### 3. Используйте кнопку

- **Первое нажатие** → Запускает выбранное действие (приложение открывается и начинается запись/трансляция)
- **Повторное нажатие** → Останавливает запись/трансляцию и закрывает приложение

## Технические детали

### Архитектура решения

Функционал реализован через следующие компоненты:

1. **MediaButtonReceiver** - `BroadcastReceiver` для перехвата медиа-событий от Bluetooth-кнопки
2. **BluetoothButtonManager** - Менеджер для управления `MediaSession` и обработки нажатий
3. **BluetoothButtonService** - Foreground Service для работы в фоновом режиме
4. **Настройки в MainActivity** - UI для управления функционалом

### Совместимость с Bluetooth-кнопками

Приложение работает с Bluetooth-кнопками, которые отправляют стандартные медиа-события:

- `KEYCODE_MEDIA_PLAY`
- `KEYCODE_MEDIA_PAUSE`
- `KEYCODE_MEDIA_PLAY_PAUSE`
- `KEYCODE_HEADSETHOOK`
- `KEYCODE_MEDIA_NEXT`
- `KEYCODE_MEDIA_PREVIOUS`

### Примеры совместимых устройств

- AB Shutter (большинство моделей)
- Selfie Button
- Media Button Remote
- Car Bluetooth Button
- Другие Bluetooth-кнопки с медиа-функциями

## Устранение неполадок

### Кнопка не реагирует

1. Убедитесь, что кнопка подключена по Bluetooth
2. Проверьте, что в настройках приложения включена обработка Bluetooth-кнопки
3. Попробуйте переподключить кнопку
4. Убедитесь, что кнопка отправляет медиа-события (проверьте, работает ли она с музыкальными плеерами)

### Запускается неправильное действие

1. Откройте настройки приложения
2. В разделе "Настройки Bluetooth-кнопки" выберите нужное действие
3. Сохраните настройки кнопкой "Готово"

### Кнопка работает только когда приложение открыто

1. Убедитесь, что приложению предоставлены все необходимые разрешения
2. Проверьте, что `BluetoothButtonService` запущен (должен быть запущен автоматически при включении функции)
3. В некоторых версиях Android может потребоваться отключить оптимизацию батареи для приложения

## Разрешения

Приложение использует следующие разрешения для работы с Bluetooth-кнопкой:

- `android.permission.FOREGROUND_SERVICE` - для работы сервиса в фоновом режиме
- `android.permission.BLUETOOTH` - для получения Bluetooth-событий (автоматически при подключении)

**Примечание**: Не требуется дополнительных разрешений для работы с медиа-кнопками!

## Интеграция с существующим функционалом

Bluetooth-кнопка полностью интегрирована с существующим функционалом приложения:

- Использует те же режимы работы (VIDEO_SEGMENTS, RTMP_STREAMING)
- Работает с той же логикой запуска/остановки, что и Quick Settings Tiles
- Сохраняет все настройки пользователя
- Отправляет сообщения и видео тем же контактам
