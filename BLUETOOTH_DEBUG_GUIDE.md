# 🔧 Отладка Bluetooth-кнопки - Пошаговая инструкция

## Проблема
Bluetooth-кнопка увеличивает громкость, но не запускает приложение.

## Решение: Пошаговая отладка

### Шаг 1: Переустановите приложение
После внесенных изменений нужна переустановка:

```bash
# Удалите старую версию
adb uninstall com.example.sostaxi

# Установите новую версию
./gradlew installDebug
```

Или просто:
1. Удалите приложение с телефона
2. Установите заново из Android Studio

### Шаг 2: Включите функцию в настройках

1. Откройте **SOSTaxi**
2. Нажмите **"Настройки"**
3. Прокрутите вниз до **"Настройки Bluetooth-кнопки"**
4. Поставьте галочку ✅ **"Включить обработку Bluetooth-кнопки"**
5. Выберите действие (видеосегменты или трансляция)

### Шаг 3: Включите службу специальных возможностей

1. В настройках приложения нажмите кнопку **"Включить службу специальных возможностей"**
2. Откроются системные настройки Android
3. Найдите **"SOS Taxi"** в списке служб
4. Нажмите на него
5. Включите переключатель вверху
6. Подтвердите предоставление доступа

### Шаг 4: Проверьте, что служба запустилась

**После включения службы должно появиться уведомление:**
```
✓ SOS Taxi: Bluetooth-кнопка активна
```

Если уведомление НЕ появилось:
- Служба не запустилась
- Попробуйте отключить и снова включить
- Перезагрузите телефон

### Шаг 5: Откройте logcat для отладки

```bash
# Фильтруем логи только нашей службы
adb logcat -s VolumeButtonAccess:D MainActivity:D BluetoothButtonManager:D
```

Или в Android Studio:
1. Откройте Logcat (внизу экрана)
2. В фильтре введите: `VolumeButtonAccess`

### Шаг 6: Нажмите на Bluetooth-кнопку и проверьте логи

**Что вы ДОЛЖНЫ увидеть в логах:**

```
D/VolumeButtonAccess: >>> onKeyEvent вызван: keyCode=24, action=0, keyName=KEYCODE_VOLUME_UP
D/VolumeButtonAccess: Bluetooth button enabled: true
D/VolumeButtonAccess: !!! ПЕРЕХВАЧЕНО НАЖАТИЕ VOLUME_UP !!!
D/VolumeButtonAccess: Вызываем handleButtonPress()
D/VolumeButtonAccess: Обработка нажатия кнопки, режим: VIDEO_SEGMENTS, активно: false
D/VolumeButtonAccess: Приложение запущено из Accessibility Service
D/VolumeButtonAccess: Блокируем изменение громкости, возвращаем true
```

## 🔍 Диагностика проблем

### Проблема 1: Не видно НИКАКИХ логов от VolumeButtonAccess

**Причина:** Служба не запущена или не подключена

**Решение:**
1. Проверьте, что служба включена в настройках специальных возможностей
2. Вы должны были увидеть лог: `=== Accessibility Service ПОДКЛЮЧЕН ===`
3. Если не видите - перезагрузите телефон
4. После перезагрузки снова включите службу

### Проблема 2: Вижу логи, но НЕ вижу "onKeyEvent вызван"

**Причина:** Служба не получает события клавиш

**Решение:**
1. Убедитесь, что в настройках службы дан полный доступ
2. Проверьте, что не отключена "Фильтрация событий клавиш"
3. Попробуйте нажать физическую кнопку громкости на телефоне - вы должны увидеть лог
4. Если физическая кнопка работает, а Bluetooth нет - проблема в самой кнопке

### Проблема 3: Вижу "onKeyEvent вызван", но keyCode НЕ 24 (VOLUME_UP)

**Причина:** Ваша кнопка отправляет другой код

**Решение:**
1. Посмотрите в логах, какой keyCode отправляет ваша кнопка
2. Например: `keyCode=25` = VOLUME_DOWN
3. Или: `keyCode=85` = MEDIA_PLAY_PAUSE
4. Измените код в VolumeButtonAccessibilityService.kt, добавив обработку этого keyCode

### Проблема 4: Вижу все логи, но приложение не запускается

**Причина:** Проблема с запуском MainActivity

**Решение:**
1. Проверьте логи MainActivity
2. Возможно, не хватает разрешений
3. Попробуйте запустить вручную через иконку приложения

### Проблема 5: Громкость все равно изменяется

**Причина:** Служба возвращает false вместо true

**Решение:**
1. Убедитесь, что вы видите лог: `Блокируем изменение громкости, возвращаем true`
2. Если не видите - значит код не доходит до return true
3. Проверьте, что `bluetooth_button_enabled` = true в настройках

## 🧪 Тестовый режим

Если ничего не работает, добавьте тестовый код:

```kotlin
// В VolumeButtonAccessibilityService.kt, в методе onKeyEvent
// Добавьте в самое начало метода:

override fun onKeyEvent(event: KeyEvent?): Boolean {
    Log.e(TAG, "!!! ТЕСТ: onKeyEvent вызван с event: $event")
    
    // Всегда показываем Toast при любой кнопке
    android.widget.Toast.makeText(
        this,
        "Кнопка: ${event?.keyCode}",
        android.widget.Toast.LENGTH_SHORT
    ).show()
    
    // ... остальной код
}
```

Это покажет Toast при ЛЮБОМ нажатии кнопки.

## 📱 Альтернативное решение (если ничего не помогает)

Если Accessibility Service не работает, можно попробовать:

1. **Использовать другую Bluetooth-кнопку** - купить кнопку, которая отправляет стандартные медиа-события
2. **Использовать приложение-ремаппер** - например, Button Mapper (в Google Play)
3. **Настроить кнопку через adb** - некоторые кнопки можно перепрограммировать
