# Инструкция по тестированию Bluetooth-кнопки

## Что изменилось

❌ **Старый подход (не работал)**: `AccessibilityService` с методом `onKeyEvent()`  
✅ **Новый подход (должен работать)**: `VolumeKeyListener` - слушатель изменений громкости

## Быстрый тест

### 1. Соберите и установите приложение
```bash
cd /Users/vlad/AndroidStudioProjects/SOSTaxi
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 2. Запустите приложение и включите функцию
- Откройте приложение
- Нажмите **"Настройки"**
- Включите **"Включить обработку Bluetooth-кнопки"**
- Выберите действие: **"Video Segments"** или **"Live Streaming"**
- Нажмите **"Готово"**

### 3. Запустите мониторинг логов
В отдельном окне терминала:
```bash
adb logcat -c
adb logcat -s "VolumeKeyListener:*" "BluetoothButtonService:*" "MainActivity:D"
```

### 4. Проверьте автозапуск сервиса
После нажатия "Готово" в логах должно появиться:
```
MainActivity          : Bluetooth-кнопка включена, запускаем сервис
BluetoothButtonService: Service onCreate
BluetoothButtonService: Service initialized (оба метода активны)
VolumeKeyListener     : Начинаем прослушивание изменений громкости
VolumeKeyListener     : Receiver зарегистрирован, текущая громкость: X
```

### 5. Закройте приложение (свернуть или выйти)
**Важно**: Сервис должен продолжать работать в фоне!

### 6. Нажмите на Bluetooth-кнопку
**Ожидаемый результат:**
- ✅ Приложение запустится автоматически
- ✅ Начнется запись/трансляция
- ✅ Громкость не изменится (восстановится автоматически)

**В логах должно появиться:**
```
VolumeKeyListener     : Громкость изменилась: 5 -> 6
VolumeKeyListener     : !!! ОБНАРУЖЕНО УВЕЛИЧЕНИЕ ГРОМКОСТИ !!!
VolumeKeyListener     : Функция включена, вызываем callback
BluetoothButtonService: VolumeKeyListener: нажатие обнаружено!
BluetoothButtonService: handleButtonPress: режим=VIDEO_SEGMENTS, активно=false
BluetoothButtonService: Приложение запущено
VolumeKeyListener     : Громкость возвращена: 6 -> 5
```

### 7. Нажмите снова (для остановки)
**Ожидаемый результат:**
- ✅ Запись/трансляция остановится
- ✅ Приложение закроется или вернется на главный экран

**В логах:**
```
VolumeKeyListener     : Громкость изменилась: 5 -> 6
VolumeKeyListener     : !!! ОБНАРУЖЕНО УВЕЛИЧЕНИЕ ГРОМКОСТИ !!!
BluetoothButtonService: handleButtonPress: режим=VIDEO_SEGMENTS, активно=true
BluetoothButtonService: Команда остановки отправлена
VolumeKeyListener     : Громкость возвращена: 6 -> 5
```

## Если не работает

### Проблема 1: Нет логов от VolumeKeyListener
**Возможные причины:**
- Сервис не запущен
- Функция отключена в настройках
- Приложение было принудительно закрыто системой

**Решение:**
1. Перезапустите приложение
2. Убедитесь, что функция включена в настройках
3. Проверьте, запущен ли сервис:
   ```bash
   adb shell dumpsys activity services | grep BluetoothButtonService
   ```

### Проблема 2: Логи есть, но приложение не запускается
**Проверьте:**
- Есть ли все необходимые разрешения?
- Не заблокирован ли запуск приложения в фоне?

**Команда для проверки:**
```bash
adb logcat -s "MainActivity:*" "BluetoothButtonService:*"
```

### Проблема 3: Громкость изменяется
**Это нормально!** Громкость кратковременно увеличивается и сразу восстанавливается.

Если громкость не восстанавливается:
- Возможно, система блокирует изменение громкости из приложения
- Проверьте режим "Не беспокоить"
